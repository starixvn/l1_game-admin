# GamesAdmin System - User Guide

## What is GamesAdmin?

GamesAdmin is a comprehensive gaming management platform that allows administrators to control and monitor all aspects of gaming operations. This system helps you manage games, track performance, handle currencies, and keep your team informed of important changes.

## 🚀 Major New Enhancements

The latest version of GamesAdmin includes three powerful new features that make your job easier and more efficient:

### 1. **AutoRNGIndex Game Creation** - Add New Games Without Code Deployment

Create new games directly through the admin interface without needing developers to deploy new code. No more waiting for development cycles - you can add games instantly when needed.

📖 **[Detailed Guide: AutoRNGIndex Game Setup](docs/AutoRNGIndex-Game-Setup-Guide.md)**

### 2. **Import/Export Settings** - Rapid Environment Setup and Configuration Management

Save and restore game settings, currency configurations, and currency group games across different environments. Set up new environments in minutes instead of hours.

📖 **[Detailed Guide: OperateSettings Import/Export](docs/OperateSettings-Import-Export-User-Guide.md)**

### 3. **Real-Time Slack Notifications** - Instant Team Communication

Automatically sends notifications to your Slack channels whenever admin changes are made. Stay informed of all changes instantly instead of relying on error monitoring.

📖 **[Detailed Guide: ChatBot Admin Notifications](docs/ChatBot-Admin-Notifications-API-Documentation.md)**
